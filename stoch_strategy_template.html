Rule & parameters — read this before trusting the numbers
  1. Entry trigger — Stochastic only, this batch. Slow %K (14-period raw %K, 3-period smoothing, 3-period %D) crossing above 80 → short; crossing below 20 → long. Only a fresh cross triggers (not every bar the reading stays extreme), and only one position is held at a time — a new signal while already in a trade is ignored.
  2. Exit — fixed points, not indicator-based. 90pt profit target or 90pt stop loss from entry, whichever a later bar's high/low touches first. Both parameters are meant to be adjustable — this run uses 90/90 as given.
  3. SMA (20), MACD (12/26/9), RSI (10), and Momentum (10) are computed and plotted but not yet wired into the entry/exit logic. The plan is to test them as confirmation filters on top of the Stochastic trigger (e.g. only take the short if price is below the SMA, or if MACD histogram agrees) — this first batch is the unfiltered baseline to compare those against.
  4. Result, honestly: this baseline loses money. 476 trades, 48.1% win rate, -1709.0pt total, -3.6pt/trade average, TP/SL hits almost evenly split (228 vs 247) — consistent with a strategy with no real edge on its own, just transaction-cost-free noise. That's not a discouraging final word on the indicator combination idea, just an honest starting point: the raw Stochastic-extreme trigger alone isn't an edge, so the interesting question is whether adding a filter changes that.
