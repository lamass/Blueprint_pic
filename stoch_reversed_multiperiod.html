This is a direct Python port of StochExtremesStrategy.cs's Stochastic-only path with ReverseAllSignals on: same %K/%D math (raw %K over the K period, smoothed, then %D as an SMA of smoothed %K), same fresh-cross-only trigger, same one-position-at-a-time, same fixed-points TP/SL checked bar-by-bar (stop assumed to win if both would hit the same bar). Run independently over every contract with cached tick history so a result found by eye on one contract in NinjaTrader can be checked for whether it generalizes — the same walk-forward discipline used throughout this project's VPIN work.
